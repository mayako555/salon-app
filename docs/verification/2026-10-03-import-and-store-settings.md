# 店舗設定・取込み修正（2026-10-03）

## 変更
- 外部スタッフ名の紐づけ：会社所属のsystemOwnerも操作可能。代理ログインからの変更は禁止を維持。取得失敗・20秒超過は再試行を表示する。
- モジュール：会社に所属するsystemOwnerの一律全機能表示を撤去。会社のモジュール設定変更を購読。スクール表示もモジュール設定を確認する。
- 弥生オンライン27列の取引TXT：UTF-8/CP932を厳密にデコード。置換文字を含むファイルは登録しない。預金・売上等は対象外、未対応科目・複合仕訳等は要確認として自動登録対象から外す。
- 同じ弥生ファイルの再送：正規化したCSV行全体のハッシュと行番号、会社IDから登録IDを決定し、トランザクションで未登録行だけ作成。ファイル内の同内容の別行は維持する。異なるファイル・手入力との類似は従来の重複候補確認を使用する。
- 店舗のsales_masterドキュメントにindustryFormsを追加保存。複数業種・複数カルテ・複数カウンセリングに対応。未設定店舗は既存会社設定を継承する。既存DBの削除・一括移行なし。
- 初期設定に店舗別設定を組込み。顧客の所属店舗から利用可能シートを取得し、カルテ作成／入力用QR発行時に選択する。保存済みカルテの編集には保存当時のシートを使用する。
