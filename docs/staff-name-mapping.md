# 外部スタッフ名の紐づけ

設定 → 外部スタッフ名の紐づけ (`/admin/settings/mappings`) で、HOT PEPPER Beautyのスタッフ名とSALON AGENTのスタッフを指定する。オーナー／管理者のみ操作でき、代理ログインからの変更は拒否する。

- `companies/{companyId}/staff_aliases` に保存。全角・半角、空白、大文字・小文字を正規化する。名前の推測や曖昧一致はしない。同姓同名は自動解決しない。
- 売上CSV取込みは「スタッフ」「担当スタッフ」「スタッフ名」を読み、元の表記を `external_staff_name` に残す。登録済みの別名を次回取込みから適用する。
- 未紐づけがある場合、取込み結果とダッシュボードのタスクに案内する。通知失敗を売上取込み失敗とは扱わない。
- スタッフ分析では別名を反映し、未紐づけ件数を案内する。雇用形態で除外されたスタッフは未紐づけ扱いにしない。
- 過去分は利用者の確認後、テナントの売上・予約を各200件ずつ走査する。続きは文書IDカーソルで確認する。既存の有効／非unknownスタッフIDは上書きしない。各書込み時にテナント・別名・スタッフを再検証し、監査ログを残す。
- 取込み時の元スタッフ名を維持し、再取込み時の重複判定を壊さない。

実データでの移行は未実施。Firestoreエミュレーターでのトランザクション検証は未実施。別名判定・曖昧名拒否・テナント外候補拒否・元の取込み識別情報の維持を単体テストで検証。Webhook等の別経路はこの機能の対象外。
